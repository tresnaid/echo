# Agent Instructions

Before performing work in this repository:

1. Read `PROJECT.md` for project-specific context and instructions.
2. Determine the activity being requested.
3. Read and follow the global standard relevant to that activity.

If `PROJECT.md` does not exist, treat the activity as project creation and follow `PROJECT_CREATION.md`.

## Activity Routing

### Creating or Establishing a Project

Read and follow:

`docs/global/PROJECT_CREATION.md`

### Normal Project Work

Read and follow:

`docs/global/WORKFLOW.md`

### Git and Pull Requests

When performing Git operations, preparing branches or worktrees, creating or updating Pull Requests, handling review changes, merging, or cleaning up:

Read and follow:

`docs/global/GIT.md`

### Documentation

When creating or updating documentation, or deciding where information should be stored:

Read and follow:

`docs/global/DOCUMENTATION.md`

### Audit and Review

When asked to audit, inspect, review, re-audit, or review a Pull Request:

Read and follow:

`docs/global/AUDIT.md`

A Pull Request review is an audit activity.

Do not review a Pull Request without first reading `AUDIT.md`.

## Multiple Activities

A task may require more than one global standard.

For example, normal implementation work that results in a Pull Request requires both `WORKFLOW.md` and the relevant procedures from `GIT.md`.

Load the standards required by the work rather than assuming one document replaces all others.

## Instruction Priority

When instructions conflict, follow this order:

1. Explicit user instructions.
2. Project-specific instructions in `PROJECT.md` or documents it references.
3. Global standards.
4. General defaults.

If a required document or instruction cannot be found or read, report the problem instead of silently continuing.
